Gestion du contenu du portfolio

Modifie le fichier de configuration data.js. Tu peux charger la version publiée, enregistrer un brouillon sur cet appareil ou télécharger le fichier modifié. Pour publier les changements pour tous les visiteurs, remplace ensuite data.js dans le dépôt GitHub et redéploie.

Ce tableau de bord fait quoi ?

  • Affiche les événements enregistrés localement sur cet appareil.
  • Permet de modifier le profil, les projets, les compétences et les informations de contenu dans data.js.
  • Exporte le fichier modifié sans toucher directement au site public.
  • Ne modifie jamais automatiquement le site en ligne.
